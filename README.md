# `dimc` — Dimensional Analysis Compiler

A compiler for a physics-based language (`.dim`) that enforces dimensional
analysis at **compile time** using 7-D unit vectors and canonical-scale
propagation, then emits pure, unit-stripped C code with **zero runtime
overhead** — the units exist only inside the compiler, so the generated C is
indistinguishable from hand-written physics code.

Built around the real-world lesson of the **Mars Climate Orbiter** failure:
the same-plus-different-units class of bugs, caught *before* the program
runs. With the Week-3 scale field, even `5 * meters + 3 * feet` (same
dimension, different canonical size) is a hard compile-time error.

## Build & Run

```bash
make clean && make
./tests/run_tests.sh                 # 16/16 cases, no skips
./output/dimc demo/mars_valid.dim    # full pipeline demo
./output/dimc -p demo/mars_valid.dim # ...and the generated main() also
                                     # PRINTS the most recently assigned
                                     # variable (the "compiler hands you
                                     # the answer" flag)
./output/dimc -r demo/mars_valid.dim # Week-5 INTERPRETER MODE: evaluate the
./output/dimc --run demo/eval_energy.dim  # program at compile time and print
                                          #   Result: 4500.00 [1,1,-1,0,0,0,0] (m*kg/s)
                                          # one Result line per bare expression
                                          # statement + the final let/assign
```

Other useful targets: `make test` (unitvec/symtab/semantic suites), and
`make audit` (portable leak audit — see QA section).

## The `.dim` language

```dim
let distance = 5 * meters;
let time     = 10 * seconds;
let speed    = distance / time;         # Length/Time
let force    = 2 * kg * meters / (seconds ^ 2);
let tiny     = 1.5e-3 * seconds;        # scientific notation
let neg      = -3 * meters;             # unary minus
```

- `let` declares, plain `name = ...` assigns (must exist).
- Unit literals (`meters`, `kg`, `seconds`, `K`, `A`, `cd`, `mol`,
  `feet`, `hours`, ...) are first-class tokens; **canonical scales** come
  from the single word table in `unitvec.c`: SI atoms ×1, `km` ×1000,
  `feet` ×0.3048, `inches` ×0.0254, `grams` ×0.001, `pounds` ×0.45359237,
  `minutes` ×60, `hours` ×3600.
- `*` `/` `^` propagate dimensions and scales (multiply / divide / raise);
  `+` `-` require **both** identical dimension vectors and equal scale.
- `^` chains fold left-associatively (`meters ^ 3 ^ 2` → `POW(meters, 6)`);
  exponents must be plain integers (fractional exponents are rejected).
- Unary minus binds looser than `^` (`-x ^ 2` == `-(x ^ 2)`);
  single-letter aliases `m`, `s`, `kg`, ... are reserved for units.

## What `dimc` emits

Every unit was checked at compile time and stripped — the generated C is
pure value code:

```c
/* generated by dimc — Dimensional Analysis compile pass */
#include <stdio.h>

int main(void) {
    double thrust    = 450;
    double time_burn = 10;
    double impulse   = thrust * time_burn;
    return 0;
}
```

Emission rules: constant subtrees fold (unit literals act as their SI
factor, so `5 * kilometers / meters` folds to `5000`); `int` declarations
only for dimensionless integer constants, else `double`; minimal
parentheses via precedence classes; `b ^ e` expands to plain multiplication
for `|e| ≤ 8`, `pow()` beyond. **stdout is pure C** — all diagnostics go to
stderr, so `./output/dimc x.dim | gcc -std=c11 -x c -` just works.

## Exit codes and test contract

| case | stdout | stderr | exit |
|---|---|---|---|
| valid program | `front end ok: N symbol(s)` + `semantic ok: N symbol(s), 0 error(s)` (checker), or pure C (`dimc`) | `declared:`/warnings | 0 |
| semantic error | `front end ok:` printed, **no** `semantic ok:`; `dimc` emits **nothing** | exact diagnostics (`ERROR:` / `note:`) | 1 |
| parse error | no contract lines / nothing | `ERROR: ... parse error` | 3 |
| bad usage / I-O | — | usage / cannot-open | 2 |
| valid program, `-r`/`--run` | `Result: <value> <[vector]> (<symbol>)` lines, nothing else | `declared:`/warnings | 0 |
| evaluation error (`-r`), e.g. division by zero | nothing | `ERROR: line N: division by zero` + note | 1 |

The runner (`tests/run_tests.sh`) greps the contract lines with `grep -F`
and never parses the AST dump.

  exit**, with two documented findings in

  everything debug goes to stderr.
